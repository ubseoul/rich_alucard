# Native production method and prompt record

The earlier ImageGen concept boards remain composition-only and are not included as native sources. After HQ's live correction, no character was manufactured by downscaling, pixelating, tracing, or sampling a concept board.

Native character candidates were constructed directly from frozen sprite anchors with nearest-neighbor, binary-alpha pixel operations at their declared native canvas. Non-character candidates use cartridge-scale pixel primitives or deterministic derivatives where the OPEN corpus explicitly permits derivation (for example LISTING from WORLD). No generative prompt was used for the corrected native character pass.

Candidate count by package: A=72, B=12, C=14, D=18, E=36, F=14, G=1, H=13.

This method record does not assert taste approval. The paired boards exist so Ube/HQ can reject any derivative that does not feel like another frame from the same cartridge.
