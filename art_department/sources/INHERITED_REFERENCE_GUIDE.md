# Required visual masters and references

Read the three frozen sheets first. All PNGs here are copied unchanged, not re-rendered. Files under `vocabulary_only/` are **not character masters**. A new Art Chat should retain this distinction even if it later reorganizes the upload files.

## Frozen essential kit

- [01 — Rich identity, pixel language and state contacts](essential_kit/01_rich_identity_pixels_states.png): primary recurring-character grammar; native and integer-enlarged views, contextual bedroom Rich, aligned curb states and material crops.
- [02 — Adult vocabulary and cast scale](essential_kit/02_adult_vocabulary_cast_scale.png): Ube TASTE PASS range, independent body axes, unchanged existing women for comparison. No ranking or universal mannequin anatomy.
- [03 — Stage geometry and camera purpose](essential_kit/03_stage_geometry_camera.png): existing docks contract and two different camera purposes. Inspection overlay, not a playable screenshot or template for Ogun's Rave.

Open sheets at100% when judging native-size panels. Application fit-to-window scaling is not the intended sprite scale.

## Working conventions

- Compatible80×96 character cells use source contact(40,88); the pixel at row87 is immediately above that edge. Bedroom Rich128×64 uses(24,56), a support reference. Do not reinterpret it as a standing foot anchor.
- The CEO reaction strip uses80×96 cells in normal/heavy/lethal order. Reaction **selection mechanics** are not an Artist decision.
- The study models share80×96 cells,54px visible height and(40,88). Their normalized stature was a comparison control, not a height rule for all women.
- Full scene coordinates are270×480. Existing battle-region assets may use270×362. Declare coordinate space and origin rather than stretching one to fit the other.
- Preserve source pixels while Engineering applies approved actor scales. Docks contract is supplied at `../01_REQUIRED_AUTHORITY/stages.js` for geometry evidence; it is not code the new Art Chat must run or change.
- The vehicle source is136×50. Current contract uses source anchor(68,50), world(168,354), scale1.75. Its visible bottom/contact discrepancy is acknowledged; do not silently fix it.
- Effects contain no target identity. Runtime composites them against the current target and chooses that target's own reaction states. No CEO-shaped masks baked into generic FX.

For exact state changes, copy/derive from the authorized named character source. Never use the generic study figure as a substitute for a missing canonical character. Never recover pixels by sampling an enlarged reference sheet when the original PNG exists here.

This minimal set is enough to understand current production judgment. It does not eliminate the need for the exact state files, masks, anchors or approved outfit references required by a future Production Card.
