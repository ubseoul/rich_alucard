# B — Combat spectacle audit

**Audit only. Four packages reviewed; zero supplemental FX.** Existing components communicate four distinct fantasies. The static boards identify placement/sequencing questions, but do not establish a missing bitmap that justifies replacing good work.

Evidence: the three asset README/manifest pairs, `docs/CURRENT_CANON.md`, relevant visual grammar, the actual PNGs, the package boards and `B_phone_*` strips. Octopus Brain has four source PNGs and canon documentation but no separate package manifest in the inspected asset inventory. `combat_inventory.json` records exact paths, dimensions, hashes and register status. Files whose register approval is unknown stay unknown even when the package has broader canon references.

The 270px strips are illustrative static compositions using unchanged source components and explicit diagnostic anchors. They are **not gameplay screenshots, timing tests or runtime acceptance**. Small actor placement deliberately exposes native-size visibility problems; the Director/runtime may use another framing. No runtime code was changed or tested.
