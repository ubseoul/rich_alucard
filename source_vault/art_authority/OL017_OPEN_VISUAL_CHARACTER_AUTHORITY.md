## 0. HOW TO USE THIS FILE

1. **This file is the identity authority.** An art agent needs nothing outside the repo for any character listed here. Quoted source lines are copied verbatim from OPEN documents; the section pointers are provenance only.
2. **Precedence:** frozen pixels > this file > everything else. If a frozen asset contradicts prose here, the pixels win; flag the conflict and do not repaint.
3. **Art-director discretion (ADD)** means: choose freely, but stay inside the character's MUST / MUST NOT lines, the project style (`references/STYLE_AUTHORITY.md`, `STYLE_FINGERPRINT.md`), and the Ship015 frozen pixel language. Record every ADD choice in the ship's DISCRETION LOG. An ADD choice becomes canon only when the anchor is ACCEPTED.
4. **Adults only.** Every character here is an adult. The 21+ rule is mandatory for every woman and every dancer. Young Mazi is authored as 19; he must read clearly as an adult man, never a minor.
5. **Ube judges before freeze** for every woman: Mama Gbenga, Auntie Grit, Granny Bing, and the HOA president if drawn as a woman.
6. **Do not confuse:** SUNDAY BEST (new Oga, Deacon Brass's grandson) ≠ UNCLE SUNDAY (frozen, different character).
7. **Anchor first, states second.** Derive every state and every downstream projection (portrait crop, top-down, tactical) from the ACCEPTED anchor. Never redesign an identity in a derivative.
