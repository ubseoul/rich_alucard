## 4. Loop handling
- **Method:** each loop is decoded to raw float PCM, leading silence trimmed (−50 dB), then an **equal-power
  tail→head crossfade** of `N = clamp(6% of duration, 50 ms, 300 ms)` is applied; output length = `L − N`; encoded
  to MP3 (stereo 128 kbps, LAME Xing/gapless header). The manifest stores `loopStart = 0` and
  `loopEnd =` the measured processed duration, so playback never depends on blind full-file looping and padding is
  never looped.
- **Coverage:** all 85 loop files received this treatment (69 top-level loop entries + 16 loop parts inside sets);
  `loopEnd` measured for every loop; **0 loop-handling failures**.
- **Files the audit flagged for explicit treatment:** the 45 loop rows with raw seam > −35 dBFS (worst `SEAL_18`,
  `CAR_I6_TURBO__high`, `CAR_V12__high`, `CAR_4CYL_HIGHREV__high`, `CAR_I6_TURBO__idle`, `REEL_LOOP`, `SEAL_13`,
  `AMB_DOCKS`, `SEAL_03`, `AMB_RAMEN`) are all crossfaded; `SEAL_06__alt1` (200 ms lead) and `AMB_CATACOMB`
  (61 ms lead) additionally received leading-silence trim. Longest processed loop 113.7 s.
- **Exceptions:** none — every loop encoded successfully.
