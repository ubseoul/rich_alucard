### FIX-01 consumption map

- `js/data/btf/new_oga_tunables.js` loads before combat, systems, minigames, and adventure content.
- `js/data/btf/combat.js` reads both archetype mappings and all four attack values from `RANewOgaTunables.combat`; no Smallie/cousin attack values are duplicated there.
- `js/systems/new_oga.js` reads trust thresholds and every Clout, Trust, and HEAT delta from the same object.
- `js/data/btf/adventures/new_oga_m1_m3.js` reads TOUGE duration/threshold and all chair parameters from the same object, including the displayed TOUGE duration.
- `js/minigames/slurp.js` reads canopy defaults and the chair completion total from the same object; it contains no duplicate F2 chair defaults.
- Authored HP (Smallie 50, cousin 40), rewards, prices, and mission outcomes are not marked tunable.
