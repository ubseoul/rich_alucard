Bound changes to F02 range presentation/style and reward copy. Accept when target type is distinguishable without color, aimed lane and reload state are obvious at native size, 390 controls work, hostage penalty/result agrees with rule, and quit restores music/phone.

**Canopy:** reuse `assets/build4/p_d/gbenga_rentals_workday_270x480.png` only after its exact register approval is confirmed, plus approved Rich apron/working state if appropriate. Missing: readable stacked/single chair silhouette and grounded drop-zone treatment. No new NPC/task system. Accept when drag start/end are visible without text rectangles, target contact aligns with floor, chair count feedback is immediate, and instruction names the actual drag action.

**Ramen:** reuse approved/corrected Rich apron and existing kitchen/environment art after approval check. Missing: small bowl/order/ingredient icons only where current art cannot serve. Do not redraw Rich. Accept when freeform tutorial is clearly one exception, later order requirements match the result, wrong input gets immediate legible feedback, clock-out receipt tells cash actually moved, and ticket is readable without zoom.

**Club:** no replacement stage/character generation. Bound work to HUD/accounting/receipt/roster hierarchy and existing portrait display. Accept first-visit charge promise, one understandable cash number, paid hit vs paid miss distinction, hype/encore feedback without duplicate meters, off-night/date explanation, free visit recovery, save/reload support/VIP consistency.

**Owambe/Senator/Jollof:** scope ruling first. Reuse approved people/dog/kitchen/tents and one short reaction state before requesting new art. Accept beginning/input/feedback/result/quit consistency; a whole new minigame is unnecessary.

**Audio for every retained game:** name entry cue, loop owner, timing source, SFX owner, quit/result transition and return cue. Test sound unlocked by ordinary input and radio pin/restore. Browser no-error output is not proof of pleasant audio or synchronization.

## Shared acceptance criteria

Native270 comparison beside ordinary club/combat; consistent pixel font, palette and squared border language; no bilinear blur or feathered alpha; actor feet/contact grounded; instructions at most3 sentences/text box; controls visible and clear for390 touch; tap/drag/key response, miss, success, score receipt, retry and quit each reviewed. Approved reference pixels are identity; screenshots govern placement. Mechanical repairs and presentation changes should be reviewed separately so an aesthetic pass cannot silently alter PLAY odds, capture bands or rewards.
