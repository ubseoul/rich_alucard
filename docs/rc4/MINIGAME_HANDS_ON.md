## Result, quit and retry contract

The host always returns `{quit:true,outcome:'quit'}` and disposes the minigame. Callers disagree: M5/M6 return directly to the same minigame node, M3/A08 count progression regardless of quit, and A54 maps quit to permanent failure. These are **caller logic**, not a reason to replace the games.034/041/009 should define reversible cancellation, authored fail-forward and explicit retry separately. Preserve poverty/free club recovery and protected PLAY probabilities.

For direct-entry receipts, distinguish host reward object from main-game balance. Ramen and Jollof accumulate rewards for the caller; direct `RAMinigames.launch` does not apply all rewards by itself. The real cook-off caller did credit500. This avoids reporting a false missing payout.
