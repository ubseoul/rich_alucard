## Engineering changes

- **Registry** (`tools/art-registry.mjs`): ingests Ship 008 by its Engineering Asset Map keys and state/layer definitions, never by filename. Layers must have exact (0,0) origin, binary alpha and their base's native size; the base's hash is verified. A corrected state delta replaces the runtime state, and the original stays registered under `superseded`. Each layer carries its Art-mapped `surfaces`.
- **Surface-scoped layers** (`js/data/btf/environments.js`, `js/data/art_integration.js`):
  - Condition layers draw above the base and below actors; foreground layers draw above actors and below the UI. Both draw only on the mapped screens.
  - `RAEnvironments.drawImage` draws every layer with its base's framing, including the throne's cover crop.
  - `baseEnv` composes a condition over another runtime environment's approved base.
- **Node table** (`js/data/art_surfaces.js`, generated by `tools/art-integration.mjs`): maps adventure nodes to the Art-mapped census screen they present. It's needed because one mapped surface (`hollow_bowl|left:rich`) has a companion bound at runtime that the census key omits; the live key `hollow_bowl|left:rich,right:<person>` still activates through the node. The gate fails if a node would belong to both a mapped and an unmapped screen of the same environment, if a mapped surface isn't a live screen, or if the table is stale.
- **Registered slot** (café): Art registered the seat/table support to one contact zone (Art board 05, internal review note). While those layers are active the `left` slot stands at x=143 on the normal contact line; elsewhere, including COOK in the music room, staging is unchanged. The runtime and the dry run read the same data.
- **Combat** (`js/data/btf/combat.js`, `js/scenes/combat2.js`):
  - `RACombatData.enemyArt` is the single source for enemy art, used by the scene, the dry run and the matrix. It replaced three copies of the state mapping.
  - A fight can hold a named frozen state (`state:'wolfed_out'` / `'rogue'`); identity-anchor event states are then not swapped in.
  - Combat now draws always-on and scoped condition layers under the dimming.
- **Content:** the A20 day-three wrap names `phil@spent_grounded`, per the Art map ("map only the listed terminal surface").
- **HOOKAH** (`js/minigames/hookah.js`): frozen seated states at native 1:1 on their contacts, seated above the score lines and clear of the antenna target. Gameplay, targets and lines are unchanged. The Rookoko figure is drawn only for an explicit ROOKOKO company.
- **Director metadata:** face boxes for the seven new character sprites, authored from the pixels (`tools/presentation/annotations.json`).
